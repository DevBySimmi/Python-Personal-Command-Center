# ⚡ Python-Personal-Command-Center
A dark futuristic personal dashboard built with Python and Tkinter, featuring task management, quick notes, daily goals, a live clock, and a Pomodoro focus timer.

✨ Features

- 🕒 Live Clock — Displays the current time and date.
- ✅ Task Manager — Add, complete, and delete tasks.
- 📝 Quick Notes — Write and save personal notes.
- 🎯 Daily Goals — Track your daily goals and progress.
- ⏱️ Focus Timer — Start, pause, and reset focus sessions.
- ⏳ Custom Timer Lengths — Choose 5, 15, 25, or 45 minutes.
- 📊 Dashboard Statistics — View task completion and goal progress.
- 💾 Local Data Storage — Save tasks, notes, and goals in a JSON file.
- 🌌 Dark Futuristic Interface — A modern dashboard with a cyber-inspired design.

🛠️ Technologies Used

- Python
- Tkinter
- JSON
- "datetime"
- "os"

🚀 Getting Started

1. Clone the repository

git clone https://github.com/YOUR-USERNAME/Python-Personal-Command-Center.git

Replace "YOUR-USERNAME" with your GitHub username.

2. Open the project folder

cd Python-Personal-Command-Center

3. Run the application

python main.py

No external Python packages are required. Python and a working Tkinter installation are needed.

🎮 How to Use

1. Open the Dashboard to view the clock and progress statistics.
2. Go to Tasks to add and manage your tasks.
3. Use Notes to write and save important information.
4. Open Focus Timer to start a focus session.
5. Visit Daily Goals to track your personal goals.
6. Close the application normally to save your latest data.

💾 Data Storage

The application stores tasks, notes, and goals locally in "command_center_data.json".

Keep this file if you want to retain your saved information. Avoid committing it to a public repository if it contains private notes or personal information.
